# A2A 金融智能体黑客松评审建议

赛题原文的“六、评审标准”为空。本项目在不修改参赛须知原文件的前提下，补出一套可执行的 100 分人工终审建议；它与产品里的自动锐评互补，不混成同一个分数。

| 维度 | 分值 | 核心证据 |
|---|---:|---|
| A2A 接入与稳定性 | 15 | Agent Card 可发现、接口可调用、鉴权清晰、错误可恢复 |
| 金融数据纪律 | 20 | 授权数据、来源与版本、point-in-time、历史成分、复权与口径 |
| 研究方法与创新 | 20 | 问题价值、方法合理、因子/策略/组合流程完整、多 Agent 协同有必要 |
| 回测与风险可信度 | 20 | 基准、成交时点、成本、滑点、可交易性、样本外、回撤与暴露 |
| 解释性与可复现性 | 15 | 假设、证据链、参数、样本期、seed、结果可复算、失败不编造 |
| 演示与提交完整度 | 10 | GitHub 或邮件材料、至少 3 个示例任务、说明文档、截图/视频、Skills 清单 |

## 一票否决

- 恶意 Agent、数据窃取、绕过权限或使用未授权数据；
- 伪造行情、财务数据、回测结果或第三方来源；
- 宣称保证收益、直接荐股、代客理财，或缺少必要风险提示；
- Agent Card 不可访问、服务无法调用，且在评审窗口内未恢复；
- 作品无法以 A2A Remote Agent 形式运行。

## 建议评分方式

自动锐评负责提供可复核证据：A2A 准入、投研 Agent 必要性、四模型金融审稿、description-only 基线和同题压测。人工终审基于上表查看真实数据调用、回测复算、创新价值与提交材料，最后给出黑客松正式名次。

作品通过 GitHub 仓库链接或发送至 `code@pandaai.online` 提交；至少准备 3 个覆盖正常任务、信息不足和风险/失败边界的示例任务。
