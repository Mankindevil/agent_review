# Panda AI锐评局品牌接入设计

## 背景

当前产品以“锐评局 · FINANCE AGENT VERDICT”为品牌，顶部使用红色旋转方块中的“锐”字。参考页面 [PandaAI 关于页](https://www.pandaaiquant.com/about) 使用黑色几何熊猫图形与 `PandaAI` 字标的横向组合。

本次将产品对外名称统一为“Panda AI锐评局”，使用参考页中的完整 PandaAI Logo，同时保持现有金融 Agent 评测系统的高对比控制台风格。品牌接入不演变为 PandaAI 官网视觉复刻。

## 目标

1. 在全站顶部清晰呈现“PandaAI + 锐评局”的联合品牌。
2. 使用与参考页一致的 PandaAI 完整 Logo，不重绘、不拉伸、不改变图形比例。
3. 保留当前导航高度、页面布局、颜色体系、卡片、按钮、动效和业务文案。
4. 让首页、评测规则、评审席、申诉页、Agent 检查台和证据页使用一致的品牌结构与页面元信息。
5. 在桌面端与移动端都保持 Logo 可读、导航可用，并满足基本无障碍要求。

## 非目标

- 不照搬 PandaAI 官网的白底、圆角大图或首页排版。
- 不重构导航、Hero、表单、结果页或评测流程。
- 不调整现有红、墨绿、荧光绿主题色。
- 不把 PandaAI Logo 放入现有红色旋转方块，也不为适配主题对 Logo 加描边、阴影、渐变或滤镜。
- 不修改评测、数据源、Runtime、API 或持久化逻辑。

## 方案选择

采用方案 1：完整 PandaAI Logo 后接产品名“锐评局”。

视觉结构为：

```text
[PandaAI 官方完整 Logo]  |  锐评局
```

用户自然读作“Panda AI锐评局”。PandaAI 是主品牌，锐评局是产品名称。细分隔线只承担层级区分，不属于 Logo 本体。

没有采用以下方案：

- “熊猫图形 + Panda AI锐评局”自组字标：更紧凑，但会偏离完整官方 Logo。
- 只显示 PandaAI Logo：无法清楚表达“锐评局”产品名。
- 把熊猫图形塞入原红色“锐”字方块：会改变 Logo 的留白与使用方式。

## 品牌组件

### 资源

新增本地品牌资源，避免运行时依赖参考网站：

- `public/assets/pandaai-logo.svg`：完整横向 Logo，用于桌面端顶部。
- `public/assets/pandaai-mark.svg`：仅几何熊猫图形，用于窄屏和 favicon。
- `public/favicon.svg`：基于官方图形资源生成的站点图标。

资源应来自 PandaAI 可授权使用的官方 SVG 或透明底 PNG。若只有参考页内联 SVG，可复用其原始几何路径，但不得凭截图描摹、自动矢量化或自行改造字标。实现前应确认品牌资源的使用授权。

### 桌面端

- 保持 `.site-header` 当前 `76px` 高度与整体布局。
- 左侧品牌区展示完整 PandaAI Logo、1px 中性色分隔线和“锐评局”。
- Logo 以约 `28px` 高度显示，宽度按原始比例自动计算。
- “锐评局”继续使用当前产品标题字体与墨绿色，不引入 PandaAI 官网整套字体。
- 原英文副标题 `FINANCE AGENT VERDICT` 移到“锐评局”下方，避免重复占用 Logo 空间。
- 品牌链接的可访问名称改为“Panda AI锐评局首页”。

### 移动端

- 在现有导航断点下切换为 PandaAI 图形标志与“锐评局”，隐藏完整 `PandaAI` 字标和英文副标题。
- 不缩小 Logo 到不可辨认尺寸；图形高度不低于 `24px`。
- 不改变现有移动导航的交互方式和顺序。

### 颜色与留白

- 参考页中的黑色 Logo 在浅色顶部直接使用原色。
- Logo 四周至少保留一个熊猫图形宽度的四分之一作为安全留白。
- 深色背景场景只有在官方资源提供反白版本时才使用反白 Logo；本次顶部是浅色背景，无需新增反白版本。

## 页面范围

统一更新以下页面的顶部品牌区：

- `public/index.html`
- `public/methodology.html`
- `public/judge.html`
- `public/appeal.html`
- `public/agent-check.html`
- `public/evidence.html`

对应样式继续保留在各页面现有 CSS 文件中。本次不新增共享样式文件，也不以品牌接入为由重构其余样式。

同步更新：

- 页面 `<title>`：以“Panda AI锐评局”开头，后接各页原有用途。
- 首页 `<meta name="description">`：只补充品牌名，不改业务定位。
- favicon 链接。
- 所有与首页品牌相关的 `aria-label`。

页面正文中的“锐评局 · 终审”等产品语义保留。“PandaAI Quant”数据源状态也保留，因为它描述的是数据源，不与产品品牌混写。

## 组件与数据边界

这是纯静态品牌层改动：

```text
本地品牌资源
  → 各页面顶部品牌链接
  → CSS 响应式规则
  → 浏览器页面标题、favicon 与无障碍名称
```

没有新增接口、脚本状态或运行时数据流。Logo 加载失败时，品牌区仍显示文本“锐评局”，页面导航和评测功能不受影响。

## 验证标准

### 视觉

1. 桌面端能完整看到 PandaAI Logo、分隔线和“锐评局”，顶部高度仍为 `76px`。
2. Logo 不变形、不裁切，不套用现有红色方块、旋转或阴影。
3. 导航项和右侧系统在线状态不发生换行或重叠。
4. 首页 Hero、送检卡、评测过程与结果区的布局和配色没有变化。
5. 移动端显示 PandaAI 图形标志与“锐评局”，不会挤出导航或造成横向滚动。

### 功能与无障碍

1. 所有页面的品牌链接都指向 `/`。
2. `aria-label` 明确为“Panda AI锐评局首页”。
3. SVG 包含可访问名称或作为装饰图形正确隐藏，由外层链接提供名称。
4. Logo 资源失败时文本品牌仍可见。
5. 键盘焦点样式和导航交互保持不变。

### 回归检查

- 在常用桌面宽度与项目现有移动断点各截图一次，对比改动前后主体区域。
- 运行现有静态检查和测试套件。
- 检查六个页面的标题、favicon、品牌链接、Logo 尺寸和响应式状态。
- 检查浏览器控制台没有新增 404、SVG 或字体错误。

## 风险与控制

- **品牌授权风险**：不从截图重制 Logo；使用 PandaAI 提供或明确允许使用的资源。
- **导航空间不足**：桌面端先限制品牌组合最大宽度；窄屏使用图形标志版本，不压缩导航文字。
- **页面样式分散**：只统一品牌组件所需规则，不顺带合并全站 CSS。
- **缓存导致旧 Logo 残留**：沿用项目现有静态资源版本参数策略更新 CSS 或资源引用。

## 完成定义

全站对外名称呈现为“Panda AI锐评局”，桌面端使用完整 PandaAI Logo 加“锐评局”，移动端使用 PandaAI 图形标志加“锐评局”；除此之外，现有 UI、交互、评测流程和业务功能保持不变。
